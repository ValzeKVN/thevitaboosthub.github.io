## Updating the site

This repo has one file that matters: `index.html`. To publish a change:

1. Go to the repo on GitHub: https://github.com/ValzeKVN/thevitaboosthub.github.io
2. Open `index.html`, click the edit (pencil) icon, or use **Add file → Upload files** to replace it
3. Commit directly to `main`
4. The live site updates automatically within a minute or two

## A note on the URL

This repo is named `thevitaboosthub.github.io`, but the account that owns it is `ValzeKVN` — GitHub only gives the clean `https://<name>.github.io` URL when the repo name exactly matches the account name. Since it doesn't match here, the site is served at:

```
https://valzekvn.github.io/thevitaboosthub.github.io/
```

To get the shorter `https://thevitaboosthub.github.io` URL, this repo would need to live under a GitHub account or organization literally named `thevitaboosthub`, or a custom domain would need to be configured under Settings → Pages.
